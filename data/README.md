# Dataset

This folder contains the synthetic dataset used in the UrbanDrop SQL Analytics project.

The dataset represents a fictional omnichannel last-mile logistics operation in Argentina and covers the period from January 2025 to August 2026.

## Tables

- `customers.csv` — Customer information and segmentation
- `products.csv` — Product catalog
- `stores.csv` — Stores and distribution center
- `couriers.csv` — Logistics providers
- `orders.csv` — Orders and fulfillment information
- `order_items.csv` — Order-level product details
- `shipments.csv` — Shipment performance, SLA and costs
- `delivery_attempts.csv` — Delivery attempts and outcomes
- `incidents.csv` — Logistics incidents, costs and resolution times

## Disclaimer

All data is synthetic and was created exclusively for portfolio and analytical purposes. It does not represent any real company or customer.
